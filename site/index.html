需要媒体手工加入 App target
  1. 下载对应 Package 的精确 tag 源码 ZIP。
  2. 解压后找到表中 RootResources/ 路径，将整个 .bundle 拖入 Xcode。
  3. 勾选 Copy items if needed 和 App target，并确认出现在 Build Phases > Copy Bundle Resources。
  4. 构建后确认最终路径为 YourApp.app/<BundleName>.bundle，不能位于 SwiftPM 自动生成的嵌套 bundle。
